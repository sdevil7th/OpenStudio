# OpenStudio 0.1.05

This candidate combines the application work reviewed in
[PR #27](https://github.com/sdevil7th/OpenStudio/pull/27), including
[PR #26](https://github.com/sdevil7th/OpenStudio/pull/26), with the Windows
installer follow-up. Review the
[cumulative application comparison since the published v0.1.03](https://github.com/sdevil7th/OpenStudio/compare/v0.1.03...v0.1.05)
and, separately, the
[installer hotfix-only comparison since v0.1.04](https://github.com/sdevil7th/OpenStudio/compare/v0.1.04...v0.1.05).
The v0.1.04 tag was created, but its release was stopped after the Windows
qualification uninstaller waited for an unattended confirmation dialog. No
0.1.04 application release or Microsoft Store update was published.

## Highlights

- Drag FX grips to reorder track, input and master chains. Changes reach the
  native processing chain and automation ownership, retain focus and support
  Undo/Redo. Edge scrolling reaches plugins outside the visible list.
- Browse NAM captures and IRs in a more compact TONE3000 library with a smaller
  branded Browse control, more space for results and layouts that adapt to
  compact rack windows. Selected capture details remain accessible.
- Expand the built-in effects and instruments with dedicated editors, retained
  engine settings, presets, Compare and Undo. These include dynamic/spectral
  and Graphic EQ, compressor profiles, gate, limiter, preamp, saturator, Gain
  Phase alignment, reverb/convolution, delay, chorus, synth, piano, guitar and
  drums. See the [capability guide](../free-plugins.md) for supported controls.
- Extend eligible plugin and FX-stage automation with Preview/Capture/Punch,
  range Trim/Fill/thinning, Touch/Latch, Cross-Over and AutoJoin. Graphical Edit
  Pitch sessions retain clip/session ownership and history; realtime Pitch
  Correct remains a separate FX path.
- Add Countdown and Stopwatch practice tools to Metronome Settings, including
  Pause/Resume, Reset and transport status. Practice timing follows processed
  audio and never stops a recording. Regular and accent click sounds can be
  selected independently.
- Expand integer export with explicit dither modes and 18/20/22-bit precision
  stored in 24-bit files. Quantization follows normalization and sample-rate
  conversion; render queue jobs retain the selected mode.
- Add distribution-native Linux packages with desktop and project-file
  associations, declared dependencies and package revisions. Preserve AppImage
  download/updater names for compatible host systems.

## Fixes

- Respect explicit unattended Windows uninstall requests without waiting for a
  confirmation dialog. Interactive uninstall still asks before removing
  user-scoped settings, managed AI files and caches; project folders outside
  AppData are retained.
- Suppress installer error dialogs when suppression is requested, cancel failed
  prerequisite retries and return a nonzero installer result when payload,
  prerequisite or startup validation fails. Validation failures remain errors.
- Exercise compiled unattended installer/uninstaller behavior before Windows
  builds. Bound installed-release CI qualification and retain separate install,
  lifecycle and uninstall evidence for diagnosing failures.
- Avoid replaying a hidden macOS mixer's initial navigation when it is shown.
  Preserve startup guards and teardown while requiring one frontend document
  per window session, including reopened editors.
- Preserve intentionally silent stereo channels, valid MIDI-only plugin
  layouts and sample-rate preparation. Retain CLAP parameter automation/state
  and Linux GUI/timer support, and preserve every URI in multi-plugin LV2
  bundles during isolated scanning.
- Keep project routing and track/clip state through save/reopen, restore sends
  atomically and reject malformed MIDI before replacing the current project.
  Audio Settings remain pending until Apply/OK and restore the previous setup
  when switching fails.
- Improve managed AI repair, checkpoint/cache validation and model-download
  reporting. Windows DirectML fallback uses a separate verified runtime. The
  release selects the published Python 3.11.15 Windows/macOS AI runtime 0.0.16
  and retains the published Linux runtime 0.0.14; archive identity, downloaded
  bytes and SHA-256 are checked before catalog publication.
- Preserve live Store readiness before GitHub publication and submit the exact
  run's MSIX independently of website dispatch. This candidate requests Store
  publication after Microsoft certification through the reviewed v0.1.05 policy.

## Known Issues

- Automated checks do not establish physical audio-interface, long-session,
  mixed-DPI, clean-machine upgrade or Store-delivered upgrade acceptance. The
  installed 0.1.04 local startup logs passed normal and safe mode; visible UI
  inspection was not asserted. The cancelled tag run passed installed Windows,
  packaged macOS and Linux lifecycle checks, but those are 0.1.04 artifacts.
- Native TONE3000 OAuth/account round trips and the original Windows/Arch
  reporter reproductions remain unverified. Browser interaction/layout results
  use fixtures and do not prove live account or catalog compatibility.
- AmpliTube wet-export parity, Nekobi VST3 state restoration and the native
  played-guitar Punch/AutoJoin timeout remain unresolved. The tested DPF 1.7
  VST3 package leaks host-context references at shutdown; this does not establish
  compatibility for all third-party plugins.
- Managed macOS AI requires Apple Silicon and macOS 14 or later, while the base
  app targets macOS 12 or later. GPU overlays require compatible drivers. Gated
  model setup, NVIDIA INT8 and subjective pitch/effects/generated-audio quality
  are not asserted.
- AppImages depend on host GTK/WebKit and FFmpeg. Native package installation
  and upgrade behavior varies by distribution. Production signing/reputation,
  Microsoft certification and release-specific installed acceptance remain
  separate checks; an accepted Store submission is not proof of publication.

## Upgrade Notes

- Upgrade from the published 0.1.03 application directly to this version once
  published. The unpublished 0.1.04 tag does not require an intermediate upgrade.
  Back up projects and presets. This follow-up does not bump a persistence or
  DSP schema.
- Install Windows updates in place. Uninstalling first is unnecessary and
  removes user-scoped OpenStudio settings, optional AI runtime/model files and
  caches. Explicit silent uninstall now honors that same cleanup intent.
- Use the native Linux package matching the distribution and CPU. If a DEB
  opens Archive Manager, select the distribution's package installer. For a
  graphical upgrade failure, close OpenStudio and use the package manager.
  Do not run the application as root.
- AI Tools Setup installs or repairs optional runtimes separately from the base
  app. Existing approved complete model caches can avoid another download;
  model-license acceptance remains a separate user decision.
