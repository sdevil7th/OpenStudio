# OpenStudio 0.1.07

The [full release comparison since v0.1.05](https://github.com/sdevil7th/OpenStudio/compare/v0.1.05...v0.1.07)
includes the free-plugin, NAM Rack and recording improvements reviewed in
[PR #31](https://github.com/sdevil7th/OpenStudio/pull/31), plus the release-wrapper
correction in [PR #33](https://github.com/sdevil7th/OpenStudio/pull/33).
The 0.1.06 tag did not produce a GitHub release or Store submission: its mounted
macOS qualification stopped at an executable-path comparison. The
[hotfix-only comparison](https://github.com/sdevil7th/OpenStudio/compare/v0.1.06...v0.1.07)
covers that correction and release records; the full feature overview below is
relative to the last published application version, 0.1.05. Testing and listening
limits remain explicit.

## Highlights

- Give the free effects and instruments more useful compact and large editors:
  primary controls stay accessible, wider views show related controls and
  analysis, and Find locates controls and workflows without silently changing
  an effect's machine or mode. Exact entry, keyboard adjustment, Compare and
  Undo retain the native parameter identities.
- Add independently switchable Fuzz alongside Octave in NAM Rack, with three
  original voices adapted to the existing Guitar/Bass profiles. Clean blend now
  lives on the pedal with a knob and recessed percentage display. It blends the input to Fuzz;
  subsequent Drive, Distortion and amp processing still apply.
- Process eligible independent native-NAM audio tracks across persistent
  workers, scaling with available physical cores. Unsupported hosted-plugin,
  MIDI and routed paths retain serial processing. This introduces no extra
  device buffering, but does not yet meet the four-track, 16-sample target.
- Add selectable Legacy/Corrected processing to selected free effects and
  instruments. Corrected paths address Pitch Correct's Custom note masks and
  rate-dependent analysis, Preamp bypass alignment, Saturator Foldback symmetry,
  and oscillator/modulation timing. New instances use Corrected; older saved
  states missing the setting retain Legacy.
- Add 41 authored Reverb voice presets and whole-collection recall while
  retaining the eight historical factory voices. Optional return-level,
  processing and Shimmer scheduling choices preserve older saved behavior.
- Add NAM Preset Library Profile review for mismatched Guitar/Bass labels and
  an explicit separate-profile copy action that preserves the original preset
  and the current rack.

## Fixes

- Compare POSIX executable identity rather than path spelling during packaged
  macOS qualification. Parent aliases such as /var and /private/var no longer
  reject the same file; different or missing executables still fail. Retain
  packaged lifecycle reports and logs when a release check fails.
- Keep pending Audio Settings selections until Apply or OK instead of allowing
  periodic device readback to replace a newly chosen buffer size. Report the
  size actually accepted by the driver and distinguish recent callback and
  track-processing failures from driver interruptions.
- Bound recording-waveform previews and serialize outstanding preview reads.
  Dragging the ruler vertically zooms around its anchor without the recording
  follow-scroll fighting the drag, including the interval between pressing
  the ruler and crossing the drag threshold. With the default ruler mapping,
  horizontal dragging sets the project/loop range; explicit Select time mappings retain
  editing time selection.
  Stop and cancelled gestures discard stale preview and viewport work.
- Copy selected audio and MIDI clips together with matching drag previews and
  one Undo step, preserving relative time and track placement. Primary-drag
  copies selected whole tracks. Piano Roll Primary-drag keeps pitch fixed;
  Shift-drag keeps note timing fixed.
- Reduce excessive gain at moderate Vintage/Sustain fuzz settings and stabilize
  downstream Distortion calculations and the shared high-pass filter at high
  oversampling. Maximum fuzz gain remains available. Stacked gain can still
  amplify input hiss; these changes do not claim a commercial pedal emulation.
- Improve Reverb damping, Hold headroom, inactive-engine retirement and Shimmer
  work scheduling. Response measurement waits for pending control writes, so
  its isolated wet-only measurement uses the displayed settings. Preserve
  compatibility paths and stored parameters across the free suite.
- Preserve finite headroom in the standalone Gate and Clean compressor, and
  include filter ringing, feedback, manual delays and instrument decay in
  export-tail bounds. Embedded NAM and coloured compatibility paths retain
  their prior bounds.
- Save NAM metadata, portable presets and Pitch Correct presets through a
  bounded atomic JSON writer instead of the project-only writer. Failed saves
  are reported without replacing the existing file or relaxing project checks.
  Pitch presets and A/B retain the processing mode that gives their note mask
  meaning; old presets without a mode recall Legacy behavior.
- Explain when NAM Rack reduces loud output peaks in plain language, separate
  recent activity from earlier events, and retain distinct emergency-fault
  messages. Numeric instrument controls do not change or add Undo history when
  focused and left without an edit.
- Require the free-suite browser qualification to export schemas from the
  current native build in Windows CI. An explicitly requested missing schema
  now fails qualification rather than silently skipping those editor checks.
- Keep TONE3000 capture-loading errors visible in compact editors when a
  request completes immediately after the details panel is collapsed.
- Preserve existing destination files when audio conversion finishes after
  its deadline, including when the child process exits between polling checks.
- Correct ARA tempo and bar reader handles on 64-bit systems, and reject invalid
  content types or event indices before reading event data.
- Make Linux desktop-entry packaging independent of the source checkout's line
  endings. Create new automatic-update staging directories with private
  permissions instead of inheriting group-write access and then rejecting
  those directories. Existing unsafe paths remain rejected.
- Preserve Store listing settings when Microsoft changes read-only metadata,
  and support validating and resuming the exact existing submission. Recovery
  tags no longer trigger ordinary application release publication.

## Known Issues

- Four monitored, recording NAM tracks at 16 samples and 4x oversampling have
  not passed the required sustained test. Retained short Debug and Release
  probes contain missed deadlines or skipped work; 8 samples is also
  unqualified. Average CPU readings and passing recording-file integrity checks
  do not establish crackle-free monitoring. Oversampling is not lowered
  automatically.
- Exact-artifact listening acceptance, physical audio/MIDI devices, long
  recording sessions and mixed-DPI usability remain separate gates. Automated
  audio checks establish specific signal, state and safety contracts, not
  subjective fuzz, pitch or reverb quality. Demanding Shimmer and Pitch Correct
  configurations retain measured deadline limits.
- Release-specific installed Windows upgrade/Repair, the affected Windows 10
  installation and current macOS package acceptance remain unverified. Linux
  automated qualification is recorded in the testing guide; physical desktop
  and audio-device acceptance of the published package remain separate gates.
  Moving Linux downloads to native packages does not prove the original
  AppImage reporter's failure resolved. Signing, reputation, Microsoft
  certification and website/update-feed publication require the final artifact.
- Previously recorded third-party plugin export/state and automation issues
  remain open in the roadmap, including AmpliTube cold-export parity, Nekobi
  restoration and the native played-guitar Punch/AutoJoin timeout. This
  release does not claim to resolve them.

## Upgrade Notes

- Back up projects and presets before upgrading. Use normal
  in-place installation when a qualified update is published. On Windows,
  uninstalling first removes user-scoped settings, optional runtimes and caches.
- Existing presets retain their compatibility mode. Newly saved Pitch presets
  include that mode explicitly. Fuzz gain changes at moderate settings may
  change sustain and the saturation of later pedals; audition saved rigs and
  adjust Fuzz Level and the rack Gate intentionally.
- OpenStudio's default shortcuts change: R records, 1/Home seeks to absolute
  project start, and +/- zoom the timeline. Track Arm and Piano Roll Select
  Range use Primary+Shift+R; Pitch Editor Select uses V. Primary means Ctrl on
  Windows/Linux and Command on macOS. Other profiles and custom overrides
  retain priority. Use Keyboard, Mouse & Trackpad to inspect effective bindings.
- Changing a plugin's Signal path resets its processing history and requires
  stopped configuration. Complete-state Undo, Compare and portable recall
  retain the selected mode.
- Select the distribution-native Linux package matching the host. Published
  download and update endpoints continue to describe the actual released
  artifacts; the release workflow updates those feeds after publication.
- The [testing guide](../testing.md), [NAM Rack guide](../nam-rack.md) and
  [free-plugin guide](../free-plugins.md) hold the workflows and qualification
  limits. Build/test results must be tied to the tested source and
  binary before release approval.
