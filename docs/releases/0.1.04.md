# OpenStudio 0.1.04

Application release candidate prepared in [PR #27](https://github.com/sdevil7th/OpenStudio/pull/27),
including the implementation reviewed in [PR #26](https://github.com/sdevil7th/OpenStudio/pull/26).
The [reviewed application comparison since v0.1.03](https://github.com/sdevil7th/OpenStudio/compare/v0.1.03...c200d7f099eee532aa7e3f471383db5438864fe6)
covers the application implementation: built-in processors and automation,
NAM/input-profile improvements, Store release safeguards and integrated Linux
support, including the Linux runtime publication follow-up. The application code
from PR #26 is retained; subsequent runtime publication guards and browser-test
setup corrections are reviewed in PR #27 and change tooling, tests and documentation.
These changes are not yet a published application release.
The separate [Linux AI runtime 0.0.14](https://github.com/sdevil7th/OpenStudio/releases/tag/ai-runtime-linux-v0.0.14)
is already published; its release is separate from this application candidate.

## Highlights

- Expand the built-in effects and instruments with dedicated editors, retained
  engine settings, presets, Compare and Undo. The suite includes dynamic/spectral
  EQ, Graphic EQ, compressor profiles, gate, limiter, preamp, saturator, Gain
  Phase alignment, reverb/convolution, delay, chorus, synth, piano, guitar and
  drums. Synthesized instruments need no additional sample pack. See the
  [capability guide](../free-plugins.md) for supported controls and limits.
- Open the existing graphical Edit Pitch session from Pitch Correct after
  selecting an eligible recorded clip, with route-conflict checks and retained
  clip/session history. Realtime Pitch Correct remains a separate FX path;
  Legacy Humanize is retained alongside the opt-in Sustained notes mode.
- Extend automation to sends, FX stages and eligible native/hosted plugin
  parameters, including master/monitor FX, JSFX and CLAP targets. Add audible
  Preview/Capture/Punch, range Trim/Fill/thinning, Touch/Latch, Cross-Over and
  AutoJoin controls. Saved parameter identity, structural routing, envelope
  history and delayed edits retain their project and plugin ownership. The
  [automation guide](../automation-host-review.md) describes supported targets
  and behavior; the played-guitar limitation below remains open.
- Refine the existing NAM Rack/TONE3000 capture and IR workflows with a compact
  branded account header, a smaller Browse button, more result-list space and
  layouts that adapt to compact hosts. Selected capture details remain available
  in an accessible disclosure. Independent keyboard and mouse/trackpad profiles
  retain configurable bindings.
- Add Countdown and Stopwatch to Metronome Settings, with Pause/Resume, Reset
  and transport status. Timed practice follows processed audio samples, ends on
  playback/recording or device loss, and never stops a recording. Choose built-in
  click sounds or a custom audio file independently for regular and accent beats.
- Expand integer export with explicit TPDF, RPDF and first/second-order shaped
  TPDF modes, plus 18/20/22-bit precision stored in 24-bit files. Final output
  quantization follows normalization and sample-rate conversion; render queue
  jobs retain the selected mode. Float and lossy exports disable dither.
- Add distribution-native Linux DEB/RPM packaging with application-menu and
  project-file association, declared runtime dependencies and package revisions.
  The AppImage remains an alternative for systems with the required GTK/WebKit
  stack. Existing AppImage asset names and updater contracts are preserved.

## Fixes

- Reorder track, input and master FX by dragging their grips without entering
  Windows' rejected native HTML drag path. Pointer and keyboard moves update the
  backend chain and automation ownership, support Undo/Redo and preserve focus.
  Edge scrolling reaches offscreen plugins; pending reorders block stale slot
  edits and history shortcuts until the native operation finishes.
- Prevent unchanged practice-timer polls from repeatedly interrupting a cold
  shortcut-dialog mount. Retain progress updates, timer controls and protection
  from stale responses.
- Keep click/release on a clip as selection rather than a snapped move. Use the
  current timeline transform for dragging and playhead placement during zoom,
  and retain visible beat/subdivision marks when their bar begins offscreen.
- Linux assets and helpers resolve beside the running ELF executable, including
  AppImage launches with misleading command names. Inherited AppImage environment
  variables cannot redirect frontend or AI script lookup. Load versioned
  GTK/WebKit libraries, enable native HTTPS and MP3 decoding, and reject Linux
  payloads newer than the Ubuntu 22.04 glibc baseline during packaging.
- Preserve intentionally silent stereo channels in playback and sends. Keep
  explicit mono handling, valid MIDI-only plugin layouts, sample-rate preparation
  and low-rate filter bounds. CLAP hosting combines parameter automation/state
  restoration with Linux GUI and per-instance timer support.
- Retain every plugin URI when scanning Linux LV2 bundles containing multiple
  plugins. Isolated probes accept URI identifiers without treating them as
  filesystem paths; catalog matching and stale-entry removal use those identities.
- Preserve track notes, folders, takes, display settings and routing through
  save/reopen. Restore complete sends atomically, including disabled sends and
  auxiliary source pairs. Reject malformed MIDI before replacing the current
  project and report rejected routing restoration.
- Keep Audio Settings changes pending until Apply/OK, retain capability discovery
  and device defaults, and restore the previous setup when a switch fails. Audio
  Settings and Plugin Browser contain keyboard focus and block background edits.
  Linux mixer faders retain vertical hit areas, keyboard control and gesture Undo.
- Keep menu actions outside the draggable titlebar so Preferences and media import
  do not accidentally start window dragging. Preserve media import ownership,
  file/folder filters and enlarged-font control layout.
- Install a Windows DirectML fallback in a separate verified runtime before
  activation, avoiding replacement of a DLL loaded by the failed CUDA candidate.
  Keep Linux release AI execution in the managed runtime, preserve POSIX Unicode
  arguments, select the requested model in setup and include download time in
  progress. Basic Pitch uses the bundled model's fixed overlapping input windows.
- Recognize complete cached ACE-Step snapshots and reject incomplete weights.
  Require nonempty stem checkpoint and configuration files in both native status
  and runtime probes. Retry empty files, reject truncated downloads and preserve
  model path collisions with actionable errors instead of reporting ready.
  Add the Radeon gfx1151 ROCm installation plan and unified GPU-memory probing.
  Python runtime packaging requires the generation worker's supported interpreter
  range. The published Linux CPU runtime uses Python 3.11.15.
- Keep the published Linux Python 3.11 runtime when generating a new application
  release's AI catalog, independently of the Windows/macOS archives. The candidate
  requires a new Python 3.11 Windows base archive before catalog promotion;
  the older Python 3.10 archive cannot run the current Audio Generation worker.
  Verify each selected published archive's URL, size and SHA-256, including the
  downloaded bytes and the archive's declared interpreter/platform identity,
  before publishing release metadata. Reject Python 3.10 archives at this gate.
- Validate reviewed AI component release notes and exact version/tag identity
  before building optional runtimes. Revalidate cached macOS archives and bind
  published runtime tags to the source commit without replacing the application's
  GitHub latest release.
- Qualify macOS optional AI archive preparation in PR CI, including source-built
  stem-separation dependencies where Python 3.11 ARM wheels are unavailable,
  before publishing a new runtime component.
- Release ignored MIDI event objects during import instead of leaking memory
  each time a file contains unsupported or metadata events.
- Cancel pending credential-lock waits when closing NAM/mixer windows, including
  when another window is waiting on an unavailable Linux Secret Service. Keep
  credential transactions intact without stalling window teardown behind them.
- Prepare Saturator and NAM delay/oversampling state for the negotiated mono or
  stereo output, and clamp Gate's initial filters below the device Nyquist limit.
  Reject alignment captures with fewer than 4,096 samples before arming; at
  8 kHz, choose a capture duration of at least two seconds.
- Preserve release-note validation and live Store preflight before publication.
  Submit the Store package independently of website dispatch failures, and verify
  package replacement, release notes and retained settings before retrying a
  Store draft upload or certification commit. This release is configured for
  automatic Store publication after Microsoft approves certification. Reject
  Store-enabled release dispatches from a branch or a mismatched tag before builds.
  Linux workflow gates include package dependencies, ABI, main/detached frontend
  readiness, render/engine checks and provenance evidence.

## Known Issues

- The managed macOS AI runtime requires Apple Silicon and macOS 14 or later.
  Its numerical-library wheels already impose this minimum in the published
  runtime; the base app targets macOS 12 or later. Managed AI archive operation
  on macOS 12/13 is not qualified.
- This application candidate is unpublished. Passing automated tests is not
  complete feature, distribution, installed-upgrade or physical-device acceptance.
  Earlier Linux checkpoints are documented in the
  [qualification plan](../linux-installation-and-qualification-plan.md),
  [native follow-up](../linux-native-followup-2026-10-01.md), and
  [AI report](../ai-ubuntu-qualification-2026-10-01.md); those results describe
  their earlier source and must not be counted as new PR #26 results.
- AppImages use host GTK/WebKit and FFmpeg; they do not provision arbitrary Linux
  installations. DEB/RPM files need a desktop package installer association.
  Ubuntu App Center may show an already-installed message for a newer package
  revision; terminal package-manager upgrade remains the documented workaround.
  Source/publisher warnings and production distribution/store signing remain open.
- The original Windows reporter reproductions of issues #7, #24 and #25 and the
  reported Arch setup in #23 remain unverified. Windows/macOS/Linux hosted native
  results and installed Linux package evidence are recorded in the
  [PR qualification report](../linux-pr26-qualification.md); evidence applies to
  its exact source and artifact.
- Native TONE3000 account/OAuth round trips remain unverified. Browser layout
  and interaction checks use fixtures and do not establish live account or
  catalog compatibility.
- Physical input monitoring, latency, reconnect/suspend, mixed-DPI desktops and
  long sessions require their own checks. Earlier Nekobi VST3 state-restoration
  and AmpliTube wet-export parity findings remain unresolved. The native
  played-guitar Punch/AutoJoin timeout remains a recorded failure.
- The tested DPF 1.7 VST3 package leaks host-context references at shutdown,
  including without an editor; processing/state checks alone do not qualify it.
  Its CLAP counterpart passes the tested processing/state/editor checks. This
  vendor-specific finding does not establish compatibility for every plugin.
- MiniMax/Stable Audio gated model setup, NVIDIA INT8 and subjective pitch,
  effects and generated-audio quality are not asserted. Listen to the exact
  retained artifacts before accepting an audio-quality claim.

## Upgrade Notes

- Back up projects and presets and retain the previous app while this candidate
  is qualified. No persistence or DSP schema is bumped by this integration;
  complete state and legacy fixtures remain part of compatibility testing.
- Existing Legacy processing defaults remain available. Original character and
  other opt-in engines are separate choices, with their own CPU/latency and
  listening limits. Review the active input profile's displayed import bindings;
  some profiles intentionally leave import shortcuts unassigned, while custom
  overrides retain precedence. Keyboard, Mouse & Trackpad remains the editor for
  these bindings.
- Use the native package matching the tested distribution/version and CPU.
  Install a newer revision in place; uninstalling first is unnecessary. Help's
  update action for native installations opens the download/package flow rather
  than replacing an AppImage. Do not run OpenStudio as root.
- If a DEB opens Archive Manager, choose the distribution's Software Install or
  Package Installer through Open With. If its graphical upgrade is unavailable,
  close OpenStudio and use `sudo apt install "/path/to/the/newer.deb"` locally.
- AI Tools Setup installs or repairs the optional managed runtime. Projects and
  model caches remain separate from the application. GPU overlays require
  compatible drivers; a complete approved model cache avoids another model
  download. Model license acceptance remains a separate user decision.
